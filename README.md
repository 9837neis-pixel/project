# 쇼핑몰 장바구니 & 할인 쿠폰

터미널에서 동작하는 온라인 쇼핑몰 장바구니입니다.
상품을 장바구니에 담고 빼고, 할인 쿠폰을 적용해 결제하며, 결제하면 재고가 줄어듭니다.

## 실행 방법

Python 3.8 이상이 필요하고, 외부 라이브러리는 쓰지 않습니다.

```bash
python shop.py
```

메뉴에서 번호를 입력하고, `q`를 입력하면 종료됩니다.

```
1.상품목록 2.담기 3.빼기 4.장바구니 5.쿠폰 6.결제 q.종료
```

## 구현한 기능

| 메뉴 | 기능 |
|---|---|
| 1. 상품목록 | 번호 · 가격 · 재고(재고가 0이면 `품절`)를 출력 |
| 2. 담기 | 상품 번호와 수량을 입력. 이미 담긴 상품이면 수량을 더함. 품절이거나 재고가 부족하면 담을 수 있는 수량을 안내 |
| 3. 빼기 | 상품 번호를 입력해 장바구니에서 제거 |
| 4. 장바구니 | 담긴 상품, 상품 합계, 할인, 배송비, 결제 금액을 출력 |
| 5. 쿠폰 | 쿠폰 목록에서 하나를 골라 적용 (한 번에 1장) |
| 6. 결제 | 영수증 출력 → 재고 감소 → 장바구니 비우기 → 쿠폰 초기화 |

**결제 금액 계산**
- 상품 합계: 가격 × 수량의 합
- 할인: 적용한 쿠폰의 `discount_amount(상품 합계)`
- 배송비: (상품 합계 − 할인)이 30,000원 이상이면 0원, 미만이면 3,000원 (장바구니가 비어 있으면 0원)
- 결제 금액: 상품 합계 − 할인 + 배송비

**입력 오류 처리:** 숫자가 아닌 입력, 없는 상품 또는 쿠폰 번호, 0개 이하 수량, 빈 장바구니에서 빼기나 결제를 하면 안내 문구를 보여 주고 메뉴로 돌아갑니다.

## 클래스 구조

| 클래스 | 역할 | 사용한 개념 |
|---|---|---|
| `Product` | 상품. 번호는 클래스 변수 `_next_id`로 자동 부여 (1, 2, 3 …) | 클래스 변수, 캡슐화 (`__stock`은 `decrease_stock()`으로만 변경) |
| `Discount` | 쿠폰의 공통 틀, 할인 0원 ("쿠폰 없음") | 상속의 부모 클래스 |
| `RateDiscount` | 비율 할인, 최대 할인 금액 제한, 원 단위 미만 버림 | 상속, 오버라이딩 |
| `FixedDiscount` | 정액 할인, 최소 구매 금액 조건 | 상속, 오버라이딩 |
| `CartItem` | 장바구니 한 줄 (상품 + 수량) | 조합 (`Product` 객체를 속성으로 가짐) |
| `Cart` | 장바구니 항목과 적용한 쿠폰을 관리하고 금액을 계산 | 조합, 다형성 (쿠폰 종류와 상관없이 `discount_amount()` 호출) |
| `Shop` | 상품 목록 · 쿠폰 목록 · 장바구니를 묶어 메뉴를 실행 | 조합 |
